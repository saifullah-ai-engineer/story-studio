# Render Plan

All relative paths are relative to plan.json. The agent must first generate shot times from SRT semantics; the script does not guess semantics. start/end are in seconds, shots are continuous and start from zero, and they must still be continuous after quantizing to the nearest frame.

Before export, form a semantic verification record per [per-shot semantic alignment](semantic-alignment.md); start/end use the verified display boundaries, and do not use the first shot's audio_start directly as the picture start.

```json
{
  "width": 1080,
  "height": 1920,
  "fps": 30,
  "crf": 18,
  "audio": "../../narration.mp3",
  "shots": [
    {"id": "S001", "image": "../../S001.png", "start": 0, "end": 19.9,
     "anchor": "SRT 对应的第一句", "zoom": [1.0, 1.12], "pivot": [0.5, 0.45]},
    {"id": "S002", "image": "../../S002.png", "start": 19.9, "end": 36.3,
     "anchor": "下一段开始", "zoom": [1.12, 1.0], "pivot": [0.5, 0.5]}
  ]
}
```

- If audio is omitted or null, the output is a silent video. When a clearly matching narration is found, use it by default; do not generate narration or add music on your own.
- zoom: scale relative to filling the frame, both values at least 1. The script interpolates from the first value to the second over the shot's push/pull segment. pivot is how the remaining crop is distributed horizontally and vertically, range 0-1; 0 is left/top, 1 is right/bottom.
- Cut-point punch zoom (on by default): keep the punch when an image hard-cuts (push in on the outgoing shot, pull back on the incoming shot), but both the incoming and outgoing moves run on slow durations. Plan-level defaults are `punch_in: 1.50` (about 1.80s), `punch_out: 1.28` (about 1.00s), `cut_punch_anim: false`. Do not turn on dynamic in/out transitions by default; the cut will flash black. A single shot can override these fields, or set `cut_punch: false` to turn it off. Video shots do not get it by default. Short shots automatically shorten the punch duration, so it does not eat the push/pull.
- Default feel: about 12% of push or pull over roughly 16-20 seconds. `amp = min(0.0065 × (end-start), 0.16)`; for a person near the edge amp≤0.12. Neighboring shots alternate between `[1.0, 1+amp]` and `[1+amp, 1.0]`. Do not compress the whole push/pull into the first few seconds.
- When the image and output ratios differ: fill proportionally and crop by pivot, without stretching. Check the subject; if the user asks for the full image, a letterboxed variant can be implemented separately.
- Output length is set by the last shot's end; it must not be shorter than the narration (tolerance 1 frame), and it should at least cover the end time of the last SRT line. Do not truncate to make it a round number.
- Width and height must be positive even numbers. fps is an integer from 1-120, default 30. Finally count by frames; time error is at most half a frame.
- By default, write the same plan as a Jianying draft, and do not generate final.mp4. The draft is generated by the built-in script using pyJianYingDraft directly.
- In the Jianying draft, zoom/pivot mean the same as in local rendering: push/pull after filling the frame, with keyframes covering the whole dwell time; add separate punch zoom keyframes at the cut. See [jianying.md](jianying.md) for paths and limits.

After generating the plan, run check_pacing.py per [pacing review](pacing-review.md). Shots shorter than 5 seconds turn off cut_punch by default, unless the user explicitly asks for punch on a short shot; do not shorten the punch duration while keeping a large zoom amplitude. There is no 10% floor on zoom amplitude; a 4-second shot is only about 2.6% at the default speed.
