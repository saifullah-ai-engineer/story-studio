# Tool Notes

Python 3.9 or higher, standard library only. On Windows, `python -X utf8` is recommended. Run the following commands in the skill directory; the script can also be replaced with an absolute path. The file argument takes the pure body-text file from this project; add quotes when the path contains spaces.

```powershell
python -X utf8 scripts/history_tool.py search --era 西汉 --limit 5
python -X utf8 scripts/history_tool.py search --era 宋代 --limit 8
python -X utf8 scripts/history_tool.py search --person 韩信
python -X utf8 scripts/history_tool.py search --template T2 --exclude-cluster 韩信之死 --limit 5
python -X utf8 scripts/history_tool.py search --query "刘询 霍光"
python -X utf8 scripts/history_tool.py read H003 H012 H022 H031 H047
python -X utf8 scripts/history_tool.py hooks --type K1 --limit 5
python -X utf8 scripts/history_tool.py hooks --person 韩信
python -X utf8 scripts/history_tool.py hooks --type K2 --include-secondary --era 西汉
python -X utf8 scripts/history_tool.py hooks --id H003
python -X utf8 scripts/history_tool.py count "正文.txt" --target 1000
python -X utf8 scripts/history_tool.py count "正文.txt" --target 1000 --tolerance 0.05
python -X utf8 scripts/history_tool.py audit "正文.txt"
python -X utf8 scripts/history_tool.py scan "用户指定的新素材目录"
python -X utf8 scripts/history_tool.py validate
```

`search`: all filter conditions must hold at the same time; era matching covers the full tag and the aliases listed in the documents, person matching is exact, and conflict matching may be a substring. Query words are split on spaces and all must match. No results means no results; do not quietly loosen the conditions. By default, results are ordered by relevance while also spreading across accounts and story clusters, and return paths and factual risks. To enlarge the sample, the assistant runs a separate query on the same template. `read` returns the original full text by default; `--clean` only shows the cleaned version and cannot replace reading the original before writing.

`count`: the whole file is treated as body text, and titles, footnotes, or Markdown are not identified automatically. By default it counts letters and digits, excluding punctuation and whitespace; `--include-punctuation` switches to counting all non-whitespace characters. The default tolerance is zero; a target mismatch exits with code 1, and an argument or file error exits with code 2. Do not use a Markdown document containing source notes as a strict body-count file.

`hooks`: searches the full opening annotation, with `--type K1` through `K9` matching only the main type by default, and `--include-secondary` also matching secondary tags; exact person, era, and ID conditions can be combined. By default it returns 5 items, spreading across accounts and story clusters, and does not loosen automatically when there are no results. Results include the early text window, the complete lead unit, the body promise, risks, the original text path, and the duration estimation method; a complete unit may run far beyond the first few seconds. Hits cannot be treated as a fact pack or an effectiveness ranking.

`audit`: after removing non-alphanumeric characters, it compares sets of consecutive 5-character fragments and returns the overlap ratio and the fragments; there is no automatic pass threshold, and it cannot catch all semantic paraphrasing. Shorter than 5 characters, there is no valid fragment, so a low overlap cannot be used to claim originality. After checking quotations, fixed names, and common expressions, decide whether rewriting is needed.

`scan`: reads only all Markdown files and computes SHA256. Identical content can identify a renamed file, new content under an old file name is marked as a change candidate, and a file that is both renamed and changed may be listed as new, requiring a person to merge by video ID. It never rewrites the source directory and never deletes files from the library.

`validate`: checks required fields, ID uniqueness, relative paths inside the library, original hashes, per-piece metadata against the master catalog, hook analysis coverage of all IDs, consistency between sources and search tags, and that each lead unit is genuinely a prefix of the body text with its character count. It does not prove that a semantic category is uniquely correct, that the history is correct, or that a new draft is good. The statistics file is a snapshot of the first analysis; incremental updates must recalculate it following the maintenance workflow.
